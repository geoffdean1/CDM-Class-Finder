# CdM Class Finder

A single-file, no-install web tool that helps Corona del Mar Middle & High School
students find their classrooms on the first days of school.

- Upload your Aeries "Student Class Schedule" PDF (parsed entirely in your browser —
  nothing is uploaded anywhere), or enter your rooms manually.
- See every one of your classes pinned on the full campus map at a glance, color-coded
  and numbered by period.
- Search for any room on campus.
- Print a one-page copy of your map + class list.

## Live site

Once GitHub Pages is enabled for this repo (see below), it will be live at:

`https://YOUR-GITHUB-USERNAME.github.io/cdm-class-finder/`

## Running locally

This is a single static HTML file — just open `index.html` in a browser. No build
step, server, or dependencies required (it loads the PDF-parsing library from a CDN).

## Notes

- The campus map and room coordinates were hand-calibrated against the school's
  published campus map image.
- If the school updates room numbers or building layout, `index.html` can be
  re-generated by re-running the calibration step against a new map image.
